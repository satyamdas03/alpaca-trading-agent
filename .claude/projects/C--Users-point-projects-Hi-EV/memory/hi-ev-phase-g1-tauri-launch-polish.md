# Hi-EV — Phase G1: Tauri Launch Polish (2026-10-04)

## Summary

Phase G1 turned the Tauri v2 skeleton into a launch-ready Windows first-run experience.

## What changed

- **Real icon set** generated by `scripts/generate_icons.py` and placed in `desktop/src-tauri/icons/`.
- **Setup wizard Python detection** in `src/ev/server/setup.py`; the HUD wizard blocks until Python 3.12+ is found.
- **Configurable global shortcut** via `EV_GLOBAL_HOTKEY` env var, parsed in `desktop/src-tauri/src/shortcut.rs`.
- **Daemon crash recovery** in `desktop/src-tauri/src/daemon.rs` and `lib.rs`: native notifications on failed start, health timeout, and unexpected exit.
- **Tray "Check for updates"** menu item hits `/update/check` and shows a native notification.
- **Clean app quit** stops the daemon child via `RunEvent::Exit` and tray Quit.
- **Tauri artifact smoke test** in `scripts/smoke_tauri.py` verifies MSI, EXE, and icon assets.
